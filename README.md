## 启动实验

需要 Node.js **22 或以上**、npm，以及能够运行 Chromium 的系统。Python 3 用于源码审计和提取测试。使用仓库中的预编译测试 SWF 不需要安装 Flash 插件或 Java；自行重新编译 AS3 夹具时才需要 Java 和对应编译工具。

在仓库根目录执行：

```bash
npm ci
npx playwright install --with-deps chromium-headless-shell
npm start
```

打开 <http://127.0.0.1:8780>。Playwright 的浏览器与系统依赖安装方式以其 [官方浏览器说明](https://playwright.dev/docs/browsers) 为依据；锁定依赖后应安装该版本对应的浏览器。

房间创建时才会启动权威 AS3 运行实例。首页和 `/health` 可以访问，说明 HTTP 服务已启动；这还不能证明 Ruffle 已加载或房间能运行。若创建房间失败，应查看服务终端的 Chromium 启动或 AS3 握手错误。

### 两人操作流程

1. 在两台电脑或两个独立浏览器中打开服务地址。
2. 一人点击“创建房间”，将六位房间码交给另一人；另一人输入房间码后点击“加入”。也可以双方点击“匹配另一位玩家”。
3. 两位玩家的客户端都完成加载后，房间进入运行状态。
4. 每人使用 WASD 或方向键移动自己的方块；空格是按钮 1，鼠标左键是按钮 2。鼠标十字标记按席位独立保存。
5. 观察两个页面收到和显示的 tick、角色位置及独立指针。失焦和断线相关行为应再用自动测试核对。

以上是实验程序的操作，不是两款原游戏的完整玩法。页面中的网络往返和状态载荷是当前连接的观察值，不代表公网延迟保证或服务器容量结论。

### 服务器配置

通过环境变量配置，示例见 [.env.example](.env.example)：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | HTTP/WebSocket 监听地址 |
| `PORT` | `8780` | 服务端口 |
| `MAX_ROOMS` | `4` | 实验房间数量上限，是保护阈值，不是压测容量 |
| `CHROMIUM_PATH` | 空 | 可选的已安装 Chromium 路径；留空使用 Playwright 对应浏览器 |

例如，允许同一局域网的设备访问：

```bash
HOST=0.0.0.0 PORT=8780 npm start
```

当前 `npm start` 从进程环境读取配置。若使用 `.env` 文件，可在 Node.js 22 下运行 `node --env-file=.env server/index.mjs`。部署到公网时，可用自己的 HTTPS 反向代理转发 HTTP 和 `/ws` 的 WebSocket 升级请求；页面会根据协议选用 `ws` 或 `wss`。

**迷宫坦克（2026-11-24）** 支持 2–6 人。在大厅给未满的对局输入房间密码即可中途加入。复活模式可立即安全入场，一命模式从下一小局参战，地图在换图时随人数扩大。对局顶部显示浏览器到对局服务器的往返延迟。`A/D` 左右转动车体，`W/S` 前进后退，空格沿车头方向射击。护甲抵消一次命中，裸车一击被摧毁。标准炮每 0.30 秒可射击一次，炮弹最多留场 12 秒，反弹以后也能击中开炮者。感应雷激活后隐形，布雷时已在感应区内的坦克需要离开再踩入才能触发。追踪导弹先自由反弹 0.65 秒，再锁定可见对手；原目标失效时会立即切换到其他可见对手，尾焰取当前锁定目标的颜色。遥控导弹用 `A/D` 施加侧向牵引，两种导弹撞墙时都只略微提速。贯穿炮蓄力 0.65 秒后沿开火方向释放穿墙宽光束，持续两秒。蓄力和照射期间车体无法移动或转向。持续照射会重复造成伤害。激光的虚线和实际命中共用最多四次反弹的路径，头尾沿路径先后通过。加特林长按热机连射，松手保留余弹。双管炮、加速器和弹道瞄准器可在场景中拾取。

默认模式为信标争夺，在线玩家过半可以切换模式。十杀竞速允许两秒后随机复活，先击毁对手 10 次获胜。最后一辆按小局决出唯一存活者，先得 3 分获胜。自毁只记录死亡，最后一辆对手自毁时该小局不计分。巡回占领中，信标每 10 秒换位，率先累计独占 20 秒获胜。实战没有时间上限，累计得分、击毁、被击毁和胜局在同一场内保留。决胜后的四秒内仍能移动、开火、拾取补给和被击毁，新增的击毁和死亡计入统计，比分和胜负已经锁定。随后显示结果并在同一房间自动续局，地图淡入。补给箱独立抽取道具和随机落点。破片弹在引爆前锁住普通炮，寿命到期、命中坦克或再次按下开火时爆炸。实心三角破片随机飞散，碰墙时消失。规则和计分由大厅进程通过 `/tank-match` 同步。

**部署入口（2026-11-25）** PCSERVER 的 `D:\GameLobby` 提供局域网和公网大厅，两者各有独立房间库。首页提供两个入口，通过浏览器探测连通性再启用局域网选项。局域网使用 `http://10.13.24.1:8787/`，公网使用 `http://39.108.93.52:10011/`。冰火人权威通道用 `10013`，闪翼双星镜像通道用 `10014`，`10015` 保留为死神 vs 火影的旧版地址。浏览器可能限制公网 HTTP 页面探测内网，遇到这种情况可直接打开局域网地址。

游戏目录、房间列表、死神 vs 火影的资源和对局连接均通过网页入口 `10011` 访问。大厅实时消息优先走同源 `/lobby`，连接超时用同一席位切回旧大厅端口。迷宫坦克优先连接 `10011` 的 `/tank-match`，同一席位也可通过 `10012` 重连。连接短暂中断时，大厅会保留当前标签页最近一次读取的数据，并在后台重试。
