# 游戏大厅封面来源

六款已有游戏从本项目实际运行的画面裁切，输出为 480 × 300 WebP。游戏名称由大厅界面单独显示。

| 游戏 | 取图版本与场景 | 公开版本资料 |
| --- | --- | --- |
| 森林神庙 | 本地 HTML5 包 `1-forest-temple` 第 2 关，森林地形和彩色液池 | [Coolmath Games](https://www.coolmathgames.com/0-fireboy-and-water-girl-in-the-forest-temple) |
| 光明神庙 | 本地 HTML5 包 `2-light-temple` 第 2 关，光线和转向装置 | [Coolmath Games](https://www.coolmathgames.com/0-fireboy-watergirl-2-light-temple) |
| 冰雪神庙 | 本地 HTML5 包 `3-ice-temple` 第 4 关，冰面和变温光束 | [Coolmath Games](https://www.coolmathgames.com/0-fireboy-watergirl-3-ice-temple) |
| 水晶神庙 | 本地 HTML5 包 `4-crystal-temple` 第 3 关，水晶传送门 | [Coolmath Games](https://www.coolmathgames.com/0-fireboy-watergirl-4-crystal-temple) |
| 闪翼双星 | 正传 `core_4_abc.swf` 的双人联机验收画面，两位角色同处「秘密实验室出口」 | [4399 正传发行页](https://www.4399.com/flash/52592.htm) |
| 死神 vs 火影 | BVN Online 3.3 固定联机构建，双人实战中黑崎一护对漩涡鸣人 | [5DPLAY 项目](https://github.com/5DPLAY-Game-Studio/BleachVsNaruto) · [固定联机提交](https://github.com/keyzf/bvn-online/tree/c7da486f78b1b9217d2e158e4c0505f2084e9ffd) |
| 迷宫坦克 | 用户提供的原创嘉年华坦克封面，压缩成 960 × 540 WebP | 用户提供的场景设计参考 |

封面位于 `public/lobby/art/covers/`。四部神庙的截图取自本地浏览器打开各自正式关卡时的画布。闪翼双星取自既有同步验收截图 `sync_seq0.png`。死神 vs 火影使用 `bvn33-net.swf`，SHA-256 为 `f60f8ea05c71fd31e896334c9b34f45d2863cb1e0d2e875d0cf977c1e625815c`。

这六张游戏截图封面由私有部署环境提供。可公开的原创迷宫坦克封面随仓库提供。云台乱斗的当前封面出处待核实，继续由本地维护。缺少任意可选封面时，页面使用游戏的主题色。更换素材和验证裁切的步骤见 [网站设计与维护流程](WEBSITE_DESIGN_WORKFLOW.md)。
